# Study Tracker 📚

A simple, interactive web application designed to help students organize their study tasks, set goals, and keep track of their progress.

 Features:

- **Task Management:** Add and manage study tasks.
- **Study Goals:** Define goals for individual study sessions.
- **Subject Organization:** Organize study activities by subject.
- **Progress Tracking:** Monitor completed and pending tasks.
- **Simple Interface:** A clean, student-friendly design.

 Built With

- HTML5
- CSS3
- JavaScript

Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start organizing your study sessions!

 Purpose

This project was built to make study planning more organized and help students approach their learning with greater focus and consistency.
